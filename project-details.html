Personal Portfolio Website

Project Overview

This project involves creating a personal portfolio website as part of my Computer Science studies at the University of Hertfordshire. The website introduces who I am, my educational background, technical interests and personal work.

Purpose of the Project

The main purpose of this project is to develop a simple and easy-to-use website that presents information about me. It also gives me an opportunity to practise HTML and CSS while learning about website structure, navigation and accessibility.

Technologies Used

  • HTML5 - To structure the web pages
  • CSS3 - To style and organise the layout
  • Visual Studio Code - For writing code

Main Features

  • Homepage with personal information
  • Technical interests page
  • Portfolio page displaying projects
  • Project details page
  • Contact page
  • Responsive layout for different devices

Learning Experience

Working on this website is helping me understand how HTML and CSS work together. I am learning how to organise content, create navigation links and improve the appearance of web pages. It is also helping me understand the importance of making websites clear and easy to use.
